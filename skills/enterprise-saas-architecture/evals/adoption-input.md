# Synthetic decision advisory

Use the enterprise-saas-architecture skill to advise on a two-week experiment for an automotive B2B2C support assistant. This is a synthetic tabletop; no production or company-system access. Use this description and public official sources if useful.

The current support workflow searches dealer-specific knowledge articles manually and takes about eight minutes per ticket according to the support manager; no time study has been performed. We have GCP and an existing vendor model contract, neither yet evaluated for this use case. Product wants to try a preview model using synthetic English, French and German dealer documents in a sandbox. They do not propose sending real customer data during the experiment.

A proposed future version would retrieve across a shared index, filter results by dealer_id, draft responses, and create service appointments through a tool. The proposal does not say where filtering or authorization occurs. We have no evidence of current implementation. The team wants speed, a clear path to production if successful, and guidance on who owns the decisions. There is no vehicle control, lending or finance-reporting functionality in the proposed experiment.

Deliver an actionable recommendation and experiment charter including evaluation, cost/operating considerations, leadership ownership and adoption conditions.
